# PDF 選頁重組工具

使用 PySide6 製作的 Windows 桌面工具，可用標籤頁開啟多個 PDF、勾選指定頁面，並依標籤與頁面排列順序重組或拆分輸出。預覽縮圖不會影響輸出品質。

## 安裝與啟動

需要 Python 3.11 以上版本及 [uv](https://docs.astral.sh/uv/)。

```powershell
uv sync
uv run pdfpick
```

## 操作方式

1. 按工具列「開啟 PDF」（Ctrl+O），一次選取多個 PDF，或從檔案總管拖入多個 PDF。各檔案以主檔名顯示在標籤頁，完整路徑顯示於目前標籤的視窗標題列與標籤 tooltip。同一路徑再次開啟會切換到既有標籤。
2. 拖曳頁面縮圖或「拖曳排序」把手時，頁面縮圖會跟隨游標，其他頁面以動畫移開並顯示插入空位。移到頁面左半部可插入其前方，右半部可插入其後方；放開確認排序，按 Esc 取消。
3. 點選各頁左上角的核取方塊，或使用「單數頁」「雙數頁」批次選取；單雙數依原始頁碼計算，只影響目前標籤。
4. 使用工具列滑桿調整 25%–200% 預覽比例，固定寬度的比例顯示位於滑桿左側。Ctrl++（或 Ctrl+=）放大、Ctrl+- 縮小，每次調整 25 個百分點；點擊比例或按 Ctrl+0 回到 100%。各檔案獨立保留比例、捲動位置、選頁與頁面排序；完整操作說明可查看比例的 tooltip。100% 對應 Windows 的 96 DPI 顯示尺度。
5. 按工具列「輸出選取頁面」（Ctrl+S 或 Ctrl+Shift+S）並指定新 PDF 的儲存位置。
6. 若要逐頁存檔，按工具列「拆分選取頁面」圖示，同樣指定儲存位置與基本檔名。程式依畫面順序將已選頁面存為獨立 PDF，例如指定 `report.pdf`，會輸出 `report_01.pdf`、`report_02.pdf`。序號從 1 開始，至少兩位，依本次輸出總數補零對齊（100 頁使用 `001`–`100`），與原始頁碼無關。已存在的單頁檔案會先詢問是否覆蓋。

標籤左侧核取方塊預設不勾選。有勾選標籤時，只輸出勾選檔案的已選頁面；沒有勾選任何標籤時，只輸出目前標籤的已選頁面。勾選檔案沒有選頁時不提供輸出頁面，不會自動改選目前檔案。拖曳標籤可調整檔案順序，輸出先依標籤順序，再依各檔內的頁面排序；拆分序號跨檔連續。按標籤右側的 × 可關閉檔案。

密碼保護的 PDF 暫不支援。輸出頁面依畫面排列順序；未勾選的頁面不會輸出。

## 語言與配色

工具列右側提供兩個三態按鈕，首次使用皆預設跟隨系統，點擊即可立即切換：

- 介面語言：跟隨系統 → 繁體中文 → English → 跟隨系統。系統顯示語言為中文時使用繁體中文，其他語言使用 English；tooltip 顯示目前模式與實際語言。
- 介面配色：跟隨系統 → 淺色 → 深色 → 跟隨系統。手動指定配色後不受系統配色變化影響，回到系統模式則即時跟隨。

選擇會記住，重新啟動仍保留。切換語言會更新既有頁面標籤、工具列、tooltip、標題、狀態與對話框，不改動檔名、選頁、頁序或比例。檔案對話框採用 Qt 介面，讓按鈕與欄位也能跟隨指定的中英文語言。

## Windows 執行檔與 macOS App／DMG

GitHub Actions 的「Build desktop apps」會在 main 更新、PR 或 Release 發佈時打包，也可在 Actions 頁面以 Run workflow 手動執行並指定分支或標籤。Release 的標籤必須包含打包設定檔。

產物包含 Windows x86_64 單一 EXE、macOS Apple Silicon（arm64）DMG，以及 SHA256 校驗檔。手動執行與一般提交的產物可從 Actions 的 Artifacts 下載；Release 發佈時會自動附加到該 Release。DMG 中可將 PDFPick.app 拖入 Applications，不需要另外安裝 Python。

目前未設定 Windows 程式碼簽章或 macOS Developer ID 簽章／公證，因此下載後可能出現系統的安全提示；這些套件並非已公證的 macOS 發行版。

打包全程在 GitHub 雲端環境執行。流程會先驗證 Qt、圖示、背景 PDF 渲染與重排輸出；macOS 使用系統內建的 ditto 與 hdiutil 建立並驗證 DMG。Actions 產物保留 30 天。

# RePDF UI 設計參考

本文件整理 RePDF 0.0.11 的實際實作，可供其他桌面專案移植。數值來自程式碼；「固定」代表明確設定尺寸，「自動」代表由 Qt、字型或內容決定。

## 1. 基本風格與單位

- 介面框架：PySide6／Qt Widgets；基礎樣式為 `Fusion`，另以 QPalette 與 QSS 自訂外觀。
- 整體採扁平工具列、細線圖示、輕量邊框、小圓角與低飽和背景。
- 除字型點數與圖示繪製座標另有說明外，尺寸皆為 **Qt 邏輯像素**。Windows 150% 顯示縮放下，34 個邏輯像素約對應 51 個實體像素。
- 「PDF 顯示比例」與作業系統 DPI 縮放分開處理，不影響按鈕與工具列尺寸。

| 最小主視窗 | 720 × 520 | 固定下限 |
| 主內容區內距 | 左 12、上 10、右 12、下 12 | 固定 |

### 工具按鈕狀態

| 狀態 | 視覺處理 |
| --- | --- |
| 一般 | 透明背景、透明邊框、正常圖示色 |
| Hover | 顯示 hover 背景色 |
| Pressed | 顯示 pressed 背景色 |
| 鍵盤焦點 | 邊框使用強調色 |
| 停用 | 背景透明，圖示與文字改用停用色 |
| 複製文字／區域 OCR 啟用 | 顯示選取背景與強調色邊框，兩種模式互斥 |

目前明確自訂 checked 背景的是複製文字與區域 OCR；其他可勾選工具（例如 Fit）仍包含 Fusion 樣式對 checked 狀態的處理，不能直接視為相同的自訂樣式。

## 4. 圖示繪製規格

| 項目 | 目前規格 |
| --- | --- |
| 設計座標範圍 | **24 × 24** |
| 預先繪製點陣圖 | **48 × 48**，透明背景 |
| 預繪倍率 | 2 倍，`QPainter.scale(2, 2)` |
| 工具列顯示尺寸 | **20 × 20** |
| 線條筆畫 | **1.0 個設計座標單位** |
| 線條樣式 | 實線 `SolidLine` |
| 線條端點 | 圓頭 `RoundCap` |
| 線條轉角 | 圓角 `RoundJoin` |
| 抗鋸齒 | 開啟 |
| 一般圖示顏色 | `QPalette.ButtonText` |
| 停用圖示顏色 | `QPalette.Disabled.ButtonText` |
| 主題更新 | palette 變更時重新產生圖示 |

筆畫縮放關係：

```text
24 × 24 設計座標：筆畫寬 1
48 × 48 預繪點陣圖：筆畫寬約 2 個點陣像素
20 × 20 顯示尺寸：筆畫寬約 1 × 20 / 24 = 0.83 個邏輯像素
```

因此，移植成 SVG 時，`viewBox="0 0 24 24"`、`stroke-width="1"`、顯示寬高 20，會較接近目前的線條重量。若直接在 20 × 20 座標下畫 1px 筆畫，視覺上會稍粗。實際邊緣仍受抗鋸齒、DPI 及點陣縮放影響。

圖示是以程式幾何繪製，再轉成點陣 QIcon；目前不是 SVG 圖示，也不是每個 DPI 下即時重新繪製的向量圖。

圖形並未全部填滿 24 × 24 畫布：例如部分圓形使用 `(3, 3, 18, 18)`，因此 20 × 20 是完整圖示畫布尺寸，實際有顏色的圖形可能更小。

### 特殊圖示

- 系統語言：細線地球。
- 指定語言：`中`／`En`，設計字型高 16px、置中；隨畫布縮放顯示。
- 系統配色：直徑 18 個設計單位的圓形，左半白、右半黑；外框仍使用當前圖示色。
- 淺色／深色：太陽／月亮。
- 區域 OCR：四角框與中央 `A`；`A` 使用設計字型高 12px、粗體。
- 標籤關閉使用文字 `×`，不是工具列的繪製圖示。
- 核取方塊勾號／部分選取線使用 16 × 16 SVG，白色筆畫寬 **2**、圓頭；與工具列細線圖示的筆畫規格不同。

| 元件 | 目前規格 |

## 6. 頁面卡片與互動

| 項目 | 目前規格 |
| --- | --- |
| 頁面卡片 | 邊框 1、圓角 8 |
| 卡片內距 | 左 11、上 9、右 11、下 11 |
| 卡片標頭與預覽間距 | 8 |
| 卡片寬度 | 預覽圖片寬度 + 24 |
| 卡片標頭 | 左側頁碼核取方塊、右側拖曳把手 |
| 頁面排序動畫 | 180ms，`OutCubic` |
| 排序插入提示 | 2px 虛線、圓角 8、強調色 |
| 文字高亮 | 強調色，alpha 90／255，約 35% 不透明度 |
| 區域 OCR 框選 | 同樣的半透明填色，另畫強調色外框 |
| 一般頁面游標 | 可拖曳時使用手形 |
| 文字選取游標 | I-beam |
| 區域 OCR 游標 | 十字 |

全螢幕預覽保留 30px 標頭區放頁面核取方塊，對頁間距 12，頁面依可用區域等比例置中。核取方塊相對頁面左緣內縮 6，標頭內上緣偏移 4。

## 7. 字型

全域文字使用 **10pt**，不是 10px。依序選擇第一個可用字型：

1. Microsoft JhengHei UI
2. Microsoft JhengHei
3. Noto Sans TC
4. Arial

若以上皆不可用，沿用 QApplication 的預設字型與大小。字型度量會影響未固定高度的控制元件與文字寬度。

## 9. 移植時優先採用的尺寸

```text
toolbar.height              = 42
toolbar.padding             = 4
toolbar.spacing             = 4
toolButton.size             = 34 × 34
toolButton.radius           = 4
toolButton.border           = 1
toolButton.iconSize         = 20 × 20
icon.designCanvas           = 24 × 24
icon.designStroke           = 1
icon.cap                    = round
icon.join                   = round
content.margin              = 12
card.gap                    = 12
card.radius                 = 8
container.radius            = 6
textButton.radius           = 5
checkbox.radius             = 3
bodyFont.pointSize          = 10
reorderAnimation.durationMs = 180
```

這組值可作為桌面工具的起點；固定按鈕尺寸、圖示畫布與筆畫比例應一起移植，不能只複製 QSS 的 `padding: 4px` 來推導按鈕大小。
